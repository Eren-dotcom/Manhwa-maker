# NEON ARCHIVE — reference pilot

A complete 10-panel episode generated by `manhwa.py demo`. It exists so you can see every artefact the
pipeline produces without generating anything yourself.

```
series.json          the bible: style block, negative block, palette, geometry, disclosure
characters/*.json    sera, kael — frozen prompt_blocks, LoRAs, wards, continuity notes
episodes/ep001.json  the panel sheet: shot / beat / pace / cast / action / dialogue
promptpack/          per-tool packs (sdxl, flux, midjourney, gemini) + queue.json + comfy runner
output/ep001/        strip-full.png · upload/ (7 platform tiles) · preview.html · manifest.json
                     · layout.json · UPLOAD.md · qc-report.md
```

Open **`output/ep001/preview.html`** in a browser — it renders the tiles at phone width with the
episode metrics and the disclosure line.

## Rebuilding it

```bash
python ../../skill/manhwa-studio/scripts/manhwa.py demo . --annotate   # from this folder
```

## Regenerating the panel art

The committed art is a small demo set; the repo may ship with **placeholder panels** instead of images
(placeholders are drawn for any panel without art, so the layout and lettering are always reviewable).
To fill them in:

```bash
python ../../skill/manhwa-studio/scripts/manhwa.py prompts 1 --tool sdxl
# generate each entry, save as art/ep001/pNNN.png
python ../../skill/manhwa-studio/scripts/manhwa.py assemble 1
python ../../skill/manhwa-studio/scripts/manhwa.py check 1 --final
```

The character sheets the panels were conditioned on are in `assets/refs/`.

## What this example demonstrates

- the shot/beat/pace grammar producing deliberate vertical rhythm (80px action gaps, 600px before the
  reveal, 700px scene transition, a silent 1000px exit to the cliffhanger)
- bubble styles: `speech`, `thought` (cloud with a dot trail), `narration` (tinted caption box),
  `sfx` (outlined, rotated display type) at four different registers
- lettering auto-placed over the calmest region of each panel
- strip slicing that lands the cuts in gutters (7 tiles, none over 1280px or 2MB)
- a passing QC gate on the script, with the one honest warning a real project would also get
  (`kael` has no LoRA/reference yet — the earliest possible drift warning)
