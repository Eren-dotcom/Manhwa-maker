# The one-page cheat sheet

## Numbers that decide everything

| Thing | Value |
| --- | --- |
| Canvas | 690px (Naver/Kakao/Lezhin) · 800px (WEBTOON) · 940px (Tapas) · 1080px (own site) |
| Scroll unit | 700–1000px ≈ one phone screen |
| Panels per unit | 3–5 (splash units: 1–2) |
| Panels per episode | 45–70 (Naver/Kakao) · 30–50 (WEBTOON) |
| Words per panel | ≤ 35 |
| Balloons per panel | ≤ 3 |
| Words per speech balloon | ≤ 12 (hard cap 90 characters) |
| Balloon safe area | 8–92% horizontal · 6–94% vertical |
| Speech type size at 800px | 24–30px |
| Gutter default | 120px (0–40 snap · 200+ pause · 600+ chapter break) |
| Panel height range | 0.5× (snap) → 2.2× (splash) of canvas width |
| Signature panels per episode | 1 (thumbnail / poster / share) |
| Full-bleeds per episode | 1–2 |
| Episode cadence | weekly, with 3 episodes buffered |

## The 8-unit episode

`hook → setup → cast → turn → escalate → reveal → breather → stinger`

- Unit 1 delivers the hook in 3 panels.
- Every unit ends with a reason to scroll (question, threat, reversal, image).
- The breather is mandatory before the cliff.
- The cliffhanger is physical contact or a face — never an explanation.

## Shot → job

`establishing` place · `wide` blocking · `full` action · `medium` conversation · `medium-close` exchange · `close-up` reaction · `extreme-close` maximum pressure · `insert` information · `over-shoulder` power · `silhouette` concealment · `panel-less` breath/shock

**Never the same shot twice in a row.**

## Direction laws

- Low angle = power. High angle = vulnerability. Dutch = wrongness (never a whole scene).
- Keep the 180° line: characters must not swap sides between panels.
- Match eyelines: who looks up at whom, and from where.
- Leading lines point down the scroll.
- Cut on action: panel N starts the swing, panel N+1 is the impact.
- A silent panel must still change something.

## Lettering laws

- Balloon shape = voice source: oval (speech), dashed/cloud (thought), spiky (shout), box (caption).
- Tails point at mouths, never at backs of heads.
- Reading order: down, then left → right. Manhwa is left-to-right.
- Captions live in the upper third and never share a lane with a balloon.
- SFX are drawn, one per panel, never over a face.
- If a balloon needs two breaths to say, it is two balloons.

## Prompt law

```
style lock → shot → angle → composition → setting → action
→ character anchors (verbatim) → lighting → palette → framing
```

- One frozen style lock for the series.
- One 35–55 word anchor per character, pasted unchanged.
- One seed per episode. Reference sheets first; panels second.
- Negative: `text, speech bubbles, watermark, extra fingers, style drift, anime screencap, photorealistic`.
- Letter in the studio, never in the model.

## QC in 10 seconds

Faces clear? Tails honest? Order obvious? Balloons inside 8–92%? Cliffhanger physical? Heights varied? Three silent panels in a row? Read it at 360px wide.

## The three questions every episode must answer

1. What did the reader learn that they did not know at the top?
2. What did it cost the protagonist?
3. Why must they open episode N+1?
